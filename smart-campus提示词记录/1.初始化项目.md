# 项目初始化（Nexora）

## 0、准备

1. 先阅读 `2.claude配置.md`：CLAUDE 规则与 9 个 skills（java-module / vue-admin-page / vue-web-page / nexora-java / nexora-front / nexora-ai-assistant / nexora-mcp / nexora-rag / nexora-multimodal）。
2. 参考源码（只读）：`smart-campus/`（迁移教学底座）、`easymall/`（借鉴 AI 智能体骨架与 MCP 工程结构）。
3. 前置依赖：JDK 21、Maven、Node ≥ 20.19、MySQL 8、Redis、Elasticsearch 8（9200）。

## 2、构建前端

### 创建工程

```
npm init vite nexora-front-admin
npm init vite nexora-front-web
```

### 安装依赖

```
npm install axios element-plus artplayer echarts hls.js md-editor-v3 @vueuse/core monaco-editor --save
npm install sass-embedded@^1.99.0 --dev
```

> `@vueuse/core` 用于 WebSocket 封装（参考 easymall 的 WebSocketProvider.vue）；`monaco-editor` 用于在线编程页。

### admin vite.config.js

```
server: {
  port: 3001,
  host: '0.0.0.0',
  hotUpdate: true,
  proxy: {
    '/api': {
      target: 'http://localhost:6061',
      changeOrigin: true,
    }
  }
}
```

### web vite.config.js

```
server: {
  port: 3000,
  host: '0.0.0.0',
  hotUpdate: true,
  proxy: {
    '/api': {
      target: 'http://localhost:6060',
      changeOrigin: true,
    },
    '/ws': {
      target: 'ws://localhost:6062',
      changeOrigin: true,
      ws: true,
    }
  }
}
```

> WebSocket 由 nexora-web 的 Netty 服务提供（端口 6062），前端通过 `/ws` 代理连接。
