# 冒泡排序

冒泡排序是一种简单的排序算法，适合学习“比较与交换”的基本思想。

## 核心思想

从数组第一个元素开始，依次比较相邻两个数。如果前一个数比后一个数大，就交换它们。每一轮结束后，最大的数会像气泡一样“浮”到数组末尾。

## 示例

对数组 `[5, 3, 8, 1]` 排序：

1. 比较 5 和 3，交换，得到 `[3, 5, 8, 1]`。
2. 比较 5 和 8，不交换。
3. 比较 8 和 1，交换，得到 `[3, 5, 1, 8]`。
4. 第一轮结束，8 已经在最后。

重复以上过程，直到没有发生交换。

## 时间复杂度

冒泡排序的时间复杂度是 O(n²)。当数据量很大时，它比快速排序慢，但它代码简单、容易理解，是学习排序算法很好的起点。

## 代码示例

```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n - 1):
        for j in range(n - 1 - i):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
    return arr
```
