# 项目构建方案（Nexora）

> 赛题 JBGS-2026-02：多模态 K12 人工智能通识课教学助手对话智能体。
> Nexora = Nexus（连接）+ Aurora（极光）。本文档是初始化与构建的唯一执行依据，配合约束体系（AGENTS.md + .codex/skills）使用。

## 0、准备

1. 先读约束（已就绪，无需创建）：工作区 `AGENTS.md` → `nexora/AGENTS.md` → `nexora/nexora-java/AGENTS.md` / `nexora/nexora-front/AGENTS.md`；技能按需加载 `.codex/skills/`（java-module / react-admin-page / react-web-page / nexora-java / nexora-front / nexora-ai-assistant / nexora-mcp / nexora-rag / nexora-multimodal）。
2. 参考源码（**只读，禁止修改**）：`参考项目/smart-campus/`（教学底座迁移来源）、`参考项目/easymall/`（AI 智能体骨架 + Netty WebSocket + MCP 工程结构借鉴来源）。
3. 前置依赖：JDK 21、Maven 3.9+、Node ≥ 20.19、MySQL 8、Redis、Elasticsearch 8（9200）。
4. 环境变量：`NEXORA_AI_API_KEY`（阿里百炼 API Key，禁止硬编码进任何配置文件）。

## 1、设计要点（构建前必须知道）

- 角色仅两类：管理员（内容运营，吸收教师职能）+ 学生；**无教师 / 班级 / 考试 / 试卷概念**，AI 智能体承担"7×24 在线教师"职责。
- 领域中心是**知识点**（knowledge_point）：串起课时、题目、知识文档、练习记录、学习路径。
- 学生端固定 5 页：AI 助教（首页）/ 个性化学习路径 / 课程教材 / 编程环境（小高及以上可见）/ 我的；练习以"对话内答题卡片 + 路径节点快测"承载。
- AI 链路：HTTP 发送（返回 messageId）→ 意图路由 → RAG / MCP 工具 / 通用对话 → Netty WebSocket 流式回推；禁止同步阻塞。
- 知识库：统一"解析 → 文本化 → 文本向量（text-embedding-v4，1024 维）→ ES"管线，**不用多模态向量模型**。

## 3、模块与端口规划

| 模块 | 包路径 / 工程 | 端口 | 职责 |
|---|---|---|---|
| nexora-common | com.nexora.common | - | PO / DTO / VO / Query、Service / Mapper、Redis 组件、AI 公共组件、异常、枚举、工具 |
| nexora-admin | com.nexora.admin | 6061 | 管理端 Controller / Biz：课程体系、知识点、题库（含 AI 出题审核）、资源、知识库、提示词、生成内容质检、学生管理、系统 |
| nexora-web | com.nexora.web | 6060（WS 6062） | 学生端 Controller / Biz：学习、练习、AI 对话（Netty WebSocket 流式）、学习路径、学习分析；MCP Client |
| nexora-mcp | com.nexora.mcp | 8084 | MCP 教学工具服务（Streamable HTTP，/mcp），暴露教学域 @Tool |
| nexora-front-admin | - | 3001 | 管理后台前端（三段式管理页） |
| nexora-front-web | - | 3000 | 学生端前端（固定 5 页 + 对话内多模态卡片） |

## 4、构建前端

### 创建工程（React + TS 模板）

```bash
cd nexora-front
npm create vite@latest nexora-front-admin -- --template react-ts
npm create vite@latest nexora-front-web -- --template react-ts
```

### 安装依赖

双工程公共：

```bash
npm install antd lucide-react axios zustand react-router-dom dayjs
npm install -D sass
```

`nexora-front-web` 追加：

```bash
npm install react-markdown remark-gfm rehype-highlight highlight.js echarts echarts-for-react artplayer hls.js @monaco-editor/react pyodide
```

`nexora-front-admin` 追加：

```bash
npm install echarts echarts-for-react @uiw/react-md-editor
```

> 说明：`pyodide` 用于浏览器端运行 Python（编程环境页，免服务端沙箱）；`@uiw/react-md-editor` 仅管理端编辑知识文档用；图标统一 `lucide-react`。

### nexora-front-admin vite.config.ts

```ts
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
  plugins: [react()],
  server: {
    port: 3001,
    host: '0.0.0.0',
    proxy: {
      '/api': {
        target: 'http://localhost:6061',
        changeOrigin: true,
      },
    },
  },
})
```

### nexora-front-web vite.config.ts

```ts
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
  plugins: [react()],
  server: {
    port: 3000,
    host: '0.0.0.0',
    proxy: {
      '/api': {
        target: 'http://localhost:6060',
        changeOrigin: true,
      },
      '/ws': {
        target: 'ws://localhost:6062',
        changeOrigin: true,
        ws: true,
      },
    },
  },
})
```

> WebSocket 由 nexora-web 的 Netty 服务提供（端口 6062），前端通过 `/ws` 代理连接；生产环境地址走 `VITE_WS_URL`。

### 前端公共基建（脚手架完成后第一项任务）

按 `nexora-front/AGENTS.md` 与 skill `nexora-front` 落地：`src/utils/request.ts`（axios 实例 + 拦截器）、token 工具、auth store（Zustand）、路由 + 守卫、消息 / 确认封装；学生端再加 `src/utils/websocket.ts` 与 AI 会话 store。页面开发严格走 `react-admin-page` / `react-web-page` skill。

## 5、构建后端

新建 `nexora-java/`，Maven 多模块，从 smart-campus 拷贝基础 pom 并改造（包名统一 `com.nexora.*`）。

迁移清单：

- 从 `smart-campus` 迁移 common / admin / web 的基建类：ResponseVO、分页基类与分页结果 VO、全局异常、业务异常、响应码枚举、登录拦截器、权限注解与 AOP、Redis 组件、自定义泛型 BaseMapper、工具类；改包名 `com.smart.campus` → `com.nexora`。
- 从 `easymall-web` 迁移 `websocket/netty/*`（NettyWebSocketStarter / HandlerWebSocket / HandlerTokenValidation / ChannelContextUtils / MessageHandler / MessageHandler4Redis / HandlerHeartBeat）与 `component/ChatComponent.java`、`LoggerAdvisor.java` 骨架；token 校验改学生端登录态（header `studentToken`）。
- 从 `easymall-mcp` 迁移工程骨架（启动类、`ServerRegisterConfig` 的 `MethodToolCallbackProvider` 注册方式）；`OrderService` 这类电商工具不迁移，教学域工具按 skill `nexora-mcp` 白名单重写。

## 9、启动顺序

1. 启动 MySQL（建库 `nexora`，执行 `nexora-java/nexora.sql`）、Redis、Elasticsearch（9200）。
2. 后端：`cd nexora-java && mvn clean install -DskipTests`。
3. 依次启动：`nexora-mcp`（8084）→ `nexora-admin`（6061）→ `nexora-web`（6060 + WS 6062）。
4. 前端：`nexora-front-admin`（3001）/ `nexora-front-web`（3000）分别 `npm install && npm run dev`。
5. 验证链路：管理端登录 → 维护课程 / 知识点 / 知识文档并重新入库 → 学生端登录（带学段）→ AI 助教对话（WebSocket 流式）→ 工具调用（查课程 / 出题 / 记录进度）→ 生成学习路径。
