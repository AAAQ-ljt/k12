# Nexora 联调验收手册

> 版本:2026-08-22(视觉对话/动画入库/本地 Pyodide 等最新变更已含)
> 用途:本手册面向**接手调试的他人**,按顺序操作即可完成环境搭建、全功能验收与问题上报。

## 1. 环境准备(一次性)

### 1.1 基础设施(本机服务)

| 服务 | 地址 | 说明 |
|---|---|---|
| MySQL | localhost:3306,库 `nexora`(root/123456) | 一键迁移:`nexora-java\sql\migrate.bat full`(建库+schema+两个增量);已初始化只升级:`migrate.bat root 123456 upgrade`。增量脚本:`20260822_student_wiki.sql`(三层目录/学习档案)、`20260822_v2_email_account.sql`(邮箱账号体系) |
| Redis | localhost:6379(database 1) | 登录态/队列 |
| Elasticsearch | localhost:9200 | 向量库,`initialize-schema=true` 自动建索引 |
| ffmpeg/ffprobe | PATH 可用 | 视频转码 |

### 1.2 账号体系(邮箱为唯一登录标识)

- `user_info`:主键 `user_id`(内部关联键,被各业务表引用,勿删);登录/注册唯一依据 = **email**(`uk_email` 唯一);`username` 已降级为昵称别名,**可重复**(`uk_username` 已删除,20260822 v2)
- 学生注册:邮箱唯一;用户名重复不再拦截;登录:邮箱+密码
- 管理端登录:配置的虚拟账号(application.yml admin 配置),与 user_info 无关

### 1.2 后端环境变量(最少 2 个)

| 变量 | 必填 | 说明 |
|---|---|---|
| `NEXORA_DEEPSEEK_API_KEY` | 是 | 对话/意图/动画/出题/整理/故事 |
| `NEXORA_DASHSCOPE_API_KEY` | 是(二选一) | 向量化 + 绘本插图的统一回退 key(阿里百炼) |
| `NEXORA_EMBEDDING_API_KEY` | 否 | 专用向量 key,缺省回退 DASHSCOPE |
| `NEXORA_IMAGE_API_KEY` | 否 | 绘本插图专用,缺省回退 DASHSCOPE |
| `NEXORA_VISION_MODEL` | 否 | 视觉对话模型,默认 `deepseek-v4-flash-vision-exp` |
| `NEXORA_MCP_CLIENT_ENABLED` | 否 | 默认 false |

> IDEA 运行时:在 Run Configuration → Environment variables 配置,配置后**彻底重启**该运行项。
> 校验:`AiChatConfig` 启动日志出现「AI 环境变量已生效: NEXORA_... (sk-….xxxx)」。

### 1.3 端口与启动顺序

| 服务 | 端口 | 目录 |
|---|---|---|
| nexora-admin | 6061 | `nexora-java/nexora-admin` |
| nexora-web | 6060(+WS 6062) | `nexora-java/nexora-web` |
| nexora-mcp | 8084(可选) | `nexora-java/nexora-mcp` |
| 管理端前端 | 3001 | `nexora-front/nexora-front-admin` |
| 学生端前端 | 3000 | `nexora-front/nexora-front-web` |

顺序:MySQL/Redis/ES → 两个后端(或 mcp)→ 两个前端。前端 dev:`npm run dev`(3000/3001)。

### 1.4 Pyodide 本地化(编程环境用,一次性)

```powershell
Copy-Item nexora-front\nexora-front-web\node_modules\pyodide\* nexora-front\nexora-front-web\public\pyodide\ -Recurse -Force
```
> 已入库 gitignore(`public/pyodide/`),换机器必须重新拷贝;未拷贝时会自动回退 CDN(需联网)。

## 3. 分功能验收清单(按顺序)

### 3.1 账号与资源中心(基础,先做)
- [ ] 学生注册/登录/退出;「我的」改年级后学段联动
- [ ] 资源中心出现「原始资料/知识页/附件」三目录(蓝标)
- [ ] 未选目录上传 `.md` 自动进「原始资料」;`.png/.pdf/.mp4` 进「附件」;「原始资料」内传 pdf 被拒

### 3.2 AI 助教(核心)
- [ ] 流式对话(打字机效果)、停止生成、会话历史/删除
- [ ] 概念问答走 RAG,回复下方出现推荐材料卡片
- [ ] 「帮我解一元二次方程」「并联电阻怎么算」→ 直出步骤(不出现「知识库参考内容」)
- [ ] 「帮我做一道练习」→ 答题卡片:作答提交即时判对错+解析+得分;可重练;刷新历史卡片保留
- [ ] 「生成一个冒泡排序的动画讲解」→ 对话内出现**小卡片(标题+步数+「查看动画讲解」按钮)**;点击跳转动画页
- [ ] 讲解回复下方动作按钮:「同步知识页」(资源中心知识页出现草稿可确认入库)/「出题练习」/「动画讲解」

### 3.3 多模态视觉对话(新)
- [ ] 输入框左侧图片按钮上传(或直接 Ctrl+V 粘贴)→ 缩略图出现在输入区 → 发送
- [ ] 提问「这张图里画了什么/帮我讲解这张图」→ AI 能描述图片内容(视觉模型)
- [ ] 发送后用户气泡显示图片缩略图;刷新历史重放仍显示
- [ ] 上传的图片出现在资源中心「附件」(自动归类),AI 有中间可识别

### 3.4 动画讲解(新形态)
- [ ] 动画列表页 `/animation`:列表卡片(标题/步数/时间)+ 「全屏播放」+ 删除
- [ ] 「全屏播放」进入 `/animation/:resourceId` 大屏页:步骤导航 + SVG 画面 + 讲解 + 上一步/下一步
- [ ] 资源中心「附件」目录能看到「动画讲解-xxx」资源(动画已入个人知识库),可删除(删除后动画页同步消失)
- [ ] 动画生成失败自动降级文字讲解,不报错

### 3.5 知识页(两段式)
- [ ] 原始资料 md → 「生成 Wiki」→ 弹窗编辑 → 「保存并确认入库」→ 知识页状态 草稿→向量化中→已入库
- [ ] 已入库后 AI 助教问答能检索到该内容并附引用
- [ ] 课程详情页「生成知识页草稿」→ 知识页出现课程草稿
- [ ] 「我的学习档案」表单保存/回显;学习路径页「AI 生成学习路径」出卡片

### 3.6 绘本(小学低年级)
- [ ] 小低账号 → 绘本页:输入主题(如「白雪公主」)→ 生成(数分钟,插图走百炼)→ 列表 → 翻页阅读(图+文+页码)→ 删除
- [ ] 插图失败页显示「本页暂无插图」,故事仍可读

### 3.7 编程环境(初中/高中)
- [ ] 编程环境:预置框架按学段切换,运行输出与耗时,改错代码显示报错
- [ ] 「保存学习」→ 原始资料出现 md → 可生成知识页
- [ ] Pyodide 本地加载(断网也能跑);Monaco 编辑器需联网

### 3.8 课程教材
- [ ] 课程列表按年级过滤;课程详情章节/课时/资源;视频(HLS)/图片/文档预览;学习进度续播

### 3.9 管理端验收
- [ ] 资源上传 → AI 文档整理(知识库管理 → AI 文档整理):AI 整理 → 编辑 → 确认入库
- [ ] 习题管理:题目 CRUD/审核;AI 出题;批量导入(docx 解析+左编右 KaTeX 预览+入库)
- [ ] 试卷管理;学习分析总览 + 用户详情六 Tab + **AI 生成学习报告**

## 4. 常见问题排查

| 现象 | 处理 |
|---|---|
| 登录 500 | MySQL url 需 `allowPublicKeyRetrieval=true`(已配置);Redis database=1 |
| AI 报错/无回复 | 环境变量未生效(彻底重启);DEEPSEEK key/额度;模型名需平台可用 |
| 注册提示用户名已注册 | 用户名忽略大小写唯一,换名或 DELETE 旧用户 |
| 图片预览/绘本页图 401 | 媒体接口公开直连,检查 WebMvcConfig 排除路径未被改 |
| Pyodide 加载失败 | 重新执行 1.4 拷贝;或检查网络(会回退 CDN) |
| Monaco 空白 | 编辑器走 CDN,需联网 |
| 绘本无插图/慢 | 百炼 key 或网络;同步+异步轮询,单页失败降级文字 |
| ES 检索无结果 | 知识页需「已确认入库」(vector_status=2);ES 9200 存活 |
| 动画列表空 | 旧数据在 ai_generation_record,新版本动画存资源中心;重新生成即可 |
| 端口占用(clean 报错) | 停掉对应 java 进程再 Build |
