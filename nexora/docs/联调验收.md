# Nexora 联调验收手册

> 版本:2026-08-22(异步绘本/豆包文生图/主题净化/小学学段限制/模型验证页等最新变更已含)
> 用途:本手册面向**接手调试的他人**,按顺序操作即可完成环境搭建、全功能验收与问题上报。

---

## 1. 环境准备(一次性)

### 1.1 基础设施(本机服务)

| 服务 | 地址 | 说明 |
|---|---|---|
| MySQL | localhost:3306,库 `nexora`(root/123456) | 一键迁移:`docs\sql\migrate.bat root 123456`(先 DROP 重建,再导入 `docs\sql\nexora.sql` **37 表基线**,随后自动执行目录下 `2026*.sql` 增量脚本补最新表/列) |
| Redis | localhost:6379(database 1) | 登录态/队列/绘本任务 |
| Elasticsearch | localhost:9200 | 向量库,`initialize-schema=true` 自动建索引 |
| ffmpeg/ffprobe | PATH 可用 | 视频转码 |

> SQL 统一收敛至 `docs\sql\`(`migrate.bat` + `nexora.sql` 基线 + `2026*.sql` 增量脚本;结构 = 基线 + 增量,增量均可重复执行)。

### 1.2 账号体系(邮箱为唯一登录标识)

- `user_info`:主键 `user_id`(内部关联键,被各业务表引用,勿删);登录/注册唯一依据 = **email**(`uk_email` 唯一);`username` 已降级为昵称别名,**可重复**(`uk_username` 已删除,20260822 v2)
- 学生注册:邮箱唯一;用户名重复不再拦截;登录:邮箱+密码
- 管理端登录:配置的虚拟账号(application.yml admin 配置),与 user_info 无关

### 1.2 后端环境变量(最少 2 个;绘本另需 ARK Key)

| 变量 | 必填 | 说明 |
|---|---|---|
| `NEXORA_DEEPSEEK_API_KEY` | 是 | 对话/意图/动画/出题/整理/故事/主题净化/视觉 |
| `NEXORA_DASHSCOPE_API_KEY` | 是(二选一) | 向量化统一 key(阿里百炼) |
| `NEXORA_ARK_API_KEY` | 否 | 豆包(火山方舟)文生图 Key,`provider=ark` 时才用(当前默认 dashscope) |
| `NEXORA_EMBEDDING_API_KEY` | 否 | 专用向量 key,缺省回退 DASHSCOPE |
| `NEXORA_IMAGE_API_KEY` | 否 | dashscope 生图专用 key,缺省回退 DASHSCOPE |
| `NEXORA_IMAGE_PROVIDER` | 否 | 文生图供应商,默认 `ark`(豆包 doubao-seedream-5-0-pro)/可切 `dashscope`(阿里百炼 qwen-image-3.0) |
| `NEXORA_VISION_MODEL` | 否 | 视觉对话模型,默认 `deepseek-v4-flash-vision-exp` |
| `NEXORA_MCP_CLIENT_ENABLED` | 否 | 已默认 `true`（2026-10-04 起 `application.yml` 默认值改为 true，无需再配）；MCP 工具（教材检索/知识页/课程/掌握度）需先启动 8084。显式置 `false` 可关闭该组能力 |

> IDEA 运行时:在 Run Configuration → Environment variables 配置,配置后**彻底重启**该运行项(`setx` 为系统级永久方案,IDEA 需完全重启才读到)。启动日志出现「AI 环境变量已生效」即成功。

### 1.3 端口与启动顺序

| 服务 | 端口 | 目录 |
|---|---|---|
| **nexora-mcp（最先启动）** | 8084(必启) | `nexora-java/nexora-mcp` |
| nexora-web | 6060(+WS 6062) | `nexora-java/nexora-web` |
| nexora-admin | 6061 | `nexora-java/nexora-admin` |
| 管理端前端 | 3001 | `nexora-front/nexora-front-admin` |
| 学生端前端 | 3000 | `nexora-front/nexora-front-web` |

**启动顺序（硬规则，2026-10-04 起）**：MySQL/Redis/ES → **nexora-mcp(8084)** →（等 5-8 秒）→ nexora-web / nexora-admin → 两个前端。
MCP 未启动时 web 仍能启动、对话照常（懒握手），但本轮不挂任何 MCP 工具（教材检索/知识页/课程/掌握度全部缺席）。
前端 dev：`npm run dev`(3000/3001)。

## 3. 分功能验收清单(按顺序)

### 3.1 账号与资源中心(基础,先做)
- [ ] 学生注册/登录/退出;「我的」改年级后学段联动
- [ ] 资源中心出现「原始资料/知识页/附件」三目录(蓝标)
- [ ] 未选目录上传 `.md` 自动进「原始资料」;`.png/.pdf/.mp4` 进「附件」;「原始资料」内传 pdf 被拒

### 3.2 AI 助教(核心)
- [ ] 流式对话(打字机效果)、停止生成、会话历史/删除;切到其他页面再切回,流式回复继续实时出现(WS 常驻)
- [ ] 概念问答走 RAG,回复下方出现推荐材料卡片
- [ ] 「帮我解一元二次方程」「并联电阻怎么算」→ 直出步骤(不出现「知识库参考内容」)
- [ ] 「帮我做一道练习」→ 答题卡片:作答提交即时判对错+解析+得分;可重练;刷新历史卡片保留
- [ ] 非小学账号:「生成一个冒泡排序的动画讲解」→ 对话内出现**小卡片(标题+步数+「查看动画讲解」按钮)**;点击跳转动画页
- [ ] **小学账号(小低/小高):无任何动画入口**(建议词/动作按钮/模式切换),说「生成一个动画讲解」→ 得到普通文字讲解
- [ ] 讲解回复下方动作按钮:「同步知识页」(资源中心知识页出现草稿可确认入库)/「出题练习」/「动画讲解」(非小学)

### 3.3 多模态视觉对话(新)
- [ ] 输入框左侧图片按钮上传(或直接 Ctrl+V 粘贴)→ 缩略图出现在输入区 → 发送
- [ ] 提问「这张图里画了什么/帮我讲解这张图」→ AI 能描述图片内容(视觉模型)
- [ ] 发送后用户气泡显示图片缩略图;刷新历史重放仍显示
- [ ] 上传的图片出现在资源中心「附件」(自动归类),AI 有中间可识别

### 3.4 动画讲解(新形态,**仅初中/高中**)
- [ ] 动画列表页 `/animation`:列表卡片(标题/步数/时间)+ 「全屏播放」+ 删除
- [ ] 「全屏播放」进入 `/animation/:resourceId` 大屏页:步骤导航 + SVG 画面 + 讲解 + 上一步/下一步
- [ ] 资源中心「附件」目录能看到「动画讲解-xxx」资源(动画已入个人知识库),可删除(删除后动画页同步消失)
- [ ] 动画生成失败自动降级文字讲解,不报错

### 3.5 知识页(两段式)
- [ ] 原始资料 md → 「生成 Wiki」→ 弹窗编辑 → 「保存并确认入库」→ 知识页状态 草稿→向量化中→已入库
- [ ] 已入库后 AI 助教问答能检索到该内容并附引用
- [ ] 课程详情页「生成知识页草稿」→ 知识页出现课程草稿
- [ ] 「我的学习档案」表单保存/回显;学习路径页「AI 生成学习路径」出卡片

### 3.6 绘本(小学阶段,**异步生成**)
- [ ] 小学账号(小低/小高均可)→ 绘本页:输入主题(建议先用原创主题如「机器人小七」)→「生成绘本」→ 按钮**立即返回并显示进度**(「AI 正在编写故事...」→「正在绘制插图 x/N 页...」)
- [ ] 生成结束后**自动打开绘本**(图+文+页码翻页),列表出现新绘本;资源中心「附件」出现「绘本」类型资源,可删除
- [ ] **切页不丢**:生成过程中切到其他页面,再切回绘本页 → 恢复进度继续显示,完成后自动打开
- [ ] **版权预设**:输入「米老鼠的故事」→ 自动改编为原创小鼠主题(任务提示"主题已自动改编")→ 全页正常出图,不触发平台版权拦截
- [ ] 插图失败页显示「本页暂无插图」+ 原因(额度/内容安全/网络),故事仍可读
- [ ] 初中/高中账号访问绘本页 → 显示「绘本面向小学阶段」占位

### 3.7 编程环境(初中/高中)
- [ ] 编程环境:预置框架按学段切换,运行输出与耗时,改错代码显示报错

### 3.11 AI 助教 × 个人知识页(MCP 工具 + 侧边抽屉,2026-09-20 新增)

- [ ] AI 助教页右上角出现「知识页」入口,点开抽屉看到自己的知识页(标题/状态/来源/更新时间),可搜索标题、按状态筛选
- [ ] 抽屉内「阅览」→ Markdown 与公式正常渲染;「编辑」→ 保存草稿 / 保存并确认入库生效;「确认入库」后状态 草稿→向量化中→已入库;「删除」二次确认后消失

- [ ] 对话「把《X》改写成面向初中的版本」→ 该页变回草稿且内容已改写
- [ ] 对话「把《C》入库」→ 状态变「已入库」,随后问该页相关知识点时 AI 能引用到
- [ ] 每次 AI 动过知识页,抽屉自动刷新(或提示「知识页已更新」)
- [ ] 越权校验:用 A 账号登录后问「列出用户 B 的知识页」→ 拒绝(不存在或无权操作)

### 3.12 判分 → 掌握度回写 + 学习进度(2026-09-22 新增)
> 口径见 `docs/开发流程.md` 7.35：掌握度 = 历史正确率；练习 ≥3 次且分数 ≥80 记为已掌握；已掌握后按 1/3/7/15/30 天排复习；掉出掌握线回炉。
- [ ] 用某个课程做一次**课时通关测验**(至少勾选 1 道挂了知识点的客观题并作答) → 提交后进入「学习路径」页
- [ ] 「学习进度」卡片出现该知识点：练习次数 +1、正确率变化、状态 Tag（进行中/已掌握）
- [ ] 同一知识点累计答对达 3 次且正确率 ≥80% → 状态变「已掌握」，并出现「下次复习」时间
- [ ] 之后再答错导致分数跌破 80 → 状态回「进行中」，出现「该复习了」标记
- [ ] 主观题：学生提交后管理端「教学业务 → 答题批阅」打分 → 学习进度里该知识点的练习次数与正确率同步变化
- [ ] 未作答的题目不计入练习次数（避免空题拉低掌握度）
- [ ] 无掌握度数据时卡片显示空态提示（"去做课时通关测验"），不报错

## 4. 常见问题排查

| 现象 | 处理 |
|---|---|
| 登录 500 | MySQL url 需 `allowPublicKeyRetrieval=true`(已配置);Redis database=1 |
| AI 报错/无回复 | 环境变量未生效(彻底重启);DEEPSEEK key/额度;模型名需平台可用 |
| 注册提示邮箱已注册 | 账号=邮箱,换邮箱注册即可(用户名可重复) |
| 图片预览/绘本页图 401 | 媒体接口公开直连,检查 WebMvcConfig 排除路径未被改 |
| Pyodide 加载失败 | 重新执行 1.4 拷贝;或检查网络(会回退 CDN) |
| Monaco 空白 | 编辑器走 CDN,需联网 |
| 绘本无插图 | 「模型验证→文生图」定位:default `ark` 时 401 = ARK Key 值不对/未配置(掩码 **** 提示);`dashscope` 时:403 FreeTierOnly=百炼额度(充值/关"仅免费额度"并确认模型已开通按量)、429 限流=稍后重试(说明网络已通)、3 次超时=IPv6 黑洞 → **临时**设用户级 `JDK_JAVA_OPTIONS=-Djava.net.preferIPv4Stack=true` 并完全重启 IDEA(用完删除,避免影响 IDE;长期方案改 IDEA 运行配置 VM options 添加该参数,只作用于该运行项);内容安全 = imageError 给出原因 |
| 绘本一直「恢复生成进度...」 | 任务在 Redis(TTL 2h),重启服务会丢任务,前端会提示失败,重新生成即可 |
| ES 检索无结果 | 知识页需「已确认入库」(vector_status=2);ES 9200 存活 |
| 动画列表空 | 旧数据在 ai_generation_record,新版本动画存资源中心;重新生成即可 |
| 小学账号还看得见动画 | 前端入口按学段隐藏(刷新页面);后端 `ANIMATION`→`CHAT` 硬拦截需要重启 web |
| 端口占用(clean 报错) | 停掉对应 java 进程再 Build |
| 对话里 AI 说「知识页服务暂不可用」/「没有 MCP 工具」 | 8084 未启动（先启动 nexora-mcp 再重启 web）；MCP 客户端已默认启用，若曾在 env 显式置 `false` 需改回。工具调用失败只影响本轮，对话与抽屉不受影响 |
| 知识页点了「确认入库」一直不变成已入库 | 看 ES(9202)是否存活;失败原因会写在知识页状态 Tag 的悬浮提示里(`vector_error`) |
