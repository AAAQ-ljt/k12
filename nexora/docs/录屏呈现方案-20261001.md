## 1. 体积预算与压缩（100MB 硬约束）

- 预算：成品 ≤95MB = 760 Mbit。**公式**：`视频码率(kbps) ≈ 760000 ÷ 秒数 − 96（音频）`
  - 11 分钟 → ≈1057 kbps；**12 分钟（本方案目标）→ ≈945 kbps**；13 分钟 → ≈880 kbps
- 屏幕内容以静态 UI 为主，1080p 下 900-1000 kbps x264 两遍压制清晰度足够。

**压制命令**（本机 ffmpeg：`E:\develop_software\java\ffmpeg\bin\ffmpeg.exe`，以 12 分钟为例）：

```bat
:: 1) 分镜无损拼合（list.txt 内按顺序写 file 'sceneXX.mkv'）
ffmpeg.exe -f concat -safe 0 -i list.txt -c copy merged.mkv

:: 2) 两遍压制（视频 945k + 音频 96k ≈ 86.6MB @12min）
ffmpeg.exe -y -i merged.mkv -c:v libx264 -b:v 945k -preset slow -pass 1 -an -f null NUL
ffmpeg.exe -y -i merged.mkv -c:v libx264 -b:v 945k -preset slow -pass 2 -c:a aac -b:a 96k -movflags +faststart nexora_demo.mp4
```

- 超了先降到 24fps 重压，再考虑码率 -5%；不要降分辨率。

### ★ 镜 6｜创新点①：知识页（会自己长大的个人 Wiki）（90s）【高一】
> 这是「对话 → 沉淀 → 检索」的完整闭环，也是别人没有的东西，值得整镜 90 秒。

- 操作：
  1. 回到镜 2 那条「机器学习」讲解回复，点 **「同步知识页」**；
  2. 右上角 **「知识页」** 打开抽屉：列表（标题/状态/来源/更新时间）、状态筛选、搜索框；刚同步的内容以**草稿**状态出现；

  4. 回到对话问 **`我之前存的关于机器学习的笔记里，价格预测公式是什么？`** → AI 引用你的知识页作答；
  5. （若开了 MCP）再补一句 **`把《机器学习》总结一下`** → 抽屉自动出现《机器学习（摘要）》草稿——对话里直接整理/合并/入库知识页。
- 解说：「这是我们认为的第一个创新点：**会自己长大的个人知识库**。学生和 AI 的每一次有价值的对话，都能一键沉淀成结构化知识页；确认入库后自动向量化进 ES，成为 AI 后续回答的私有资料——学习过程本身在持续生产学习资产。RAG 检索个人库优先、官方库兜底，用 MCP 工具让大模型自己整理/合并/入库，全程白名单化。」
- 踩坑：状态「向量化中」停留几秒属正常（ES 入库），**抽屉状态列不会自动刷新，点抽屉里的「刷新」按钮**就能看到「已入库」；个人库命中时 AI 会说「你的知识页」，官方库命中会说「平台课程知识库」，两个口径可以在同一镜里对比（镜 2 已演示官方口径）。

## 2.1 二期新增分镜（2026-10-07 补，插入位置见每镜说明）

> 原 16 镜（镜 0～镜 15）不复用编号，保持原样；下面 4 镜按「插入位置」拼进成片即可。
> 建议把新镜头插在原有创新点镜头之后，形成"路径→激励→个性化"的连续叙事。

### ★ 镜 A｜成长中心：把学习变成看得见的进度（70s）【初二账号或小低账号各录一版】

- **插入位置**：紧接原镜 13（学习路径闭环）之后。
- **内容**：进入「我的」→ 成长中心卡片 → 成长环（等级/段位或"N 颗星"）→ 今日积分与上限进度 → 「明细」滚动列表 → 「徽章墙」（未解锁压暗并显示 `3/7 天` 这类进度）→ 「排行榜」（本周榜/累计榜切换，注意榜上昵称已脱敏）→ 「兑换」（额度扩容、朗读音色解锁）。
- **解说词**：积分不是装饰：签到、课时测验、节点快测、编程通关、绘本创作、知识页入库都会进账；每笔都带唯一业务键，重复事件不会重复发。
- **学段差异要露一手**：小低账号里同样的界面叫「星星」且**没有排行榜**（服务端返回不开放），初高账号才有段位与榜单——这是"学段自适应"最直观的一镜。
- **前提**：该账号先积累少量数据（签到 + 一次节点快测），否则徽章墙全灰、榜单只有自己。

### ★ 镜 B｜学习路径 × AI 助教：一键直达与"带我一轮复习"（80s）【初二账号】

- **插入位置**：可取代原镜 2 的一部分，或紧接镜 A。
- **内容**：路径详情 → 点节点 → 「复盘我最近的练习」→ **自动跳进对话并已发出提问**（不用手点发送）→ AI 回答里引用"掌握度 60、已练习 5 次、正确率 60%"，并说明"系统只记录练习次数与正确率、没有逐题记录，所以我无法直接告诉你错在哪道题"（诚实边界也是加分点）→ 再演示「带我一轮复习」（讲两三句 → 出 3 题 → 按结果决定回炉或进下一节点）。
- **要讲的机制**：提问里带的是**该学生此刻的真实数据**（路径名、节点状态、掌握度、练习次数、下次复习时间、本节点任务），不是一句空话；提示词里有"学习数据来源规则"，要求模型必须先查工具、且不得回答"没有你的数据"。
- **对比镜头（可选，很有说服力）**：先在对话里直接问「我下一步该学什么」→ AI 调用 `planNextStep` 给出真实清单（到期待复习 → 进行中节点 → 薄弱知识点，例："历史地图与疆域变迁（掌握度 60，练习 5 次）"）。

### ★ 镜 C｜教材书目"全量回答"（35s）【初二账号】

- **插入位置**：接原镜 9（课程教材）之后。
- **内容**：问「知识库中我这个年级有哪些书？」→ AI 按学科分组给出**完整清单**（初中 42 本：语文 6 / 数学 6 / 生物 4 / 物理 3 / 历史 6 / 化学 2 …），并声明"以下为完整清单"。
- **要讲的点**：这条修复很典型——不是模型编造，而是工具此前**截断到 20 条**导致模型只能按残缺数据作答；修复后工具给全量并明示完整，模型就不会"漏书或补书"。评委爱听这种"从现象追到根因"的故事。

### ★ 镜 D｜绘本朗读与音色（45s）【小学账号】

- **插入位置**：原镜 7（绘本）之后，作为其延伸。
- **内容**：绘本阅读器 → 音色下拉（未解锁项置灰并标「🔒 名字（150 分解锁）」）→ 回到成长中心「兑换」用积分解锁一个音色 → 回到绘本切换该音色朗读。
- **要讲的点**：音色解锁是"零履约成本"的激励设计——一份"已解锁音色集合"，现在服务在绘本朗读，将来 AI 助教的朗读直接继承同一份解锁状态（一处门禁、多处生效）。

## 4. 录制执行细节

- **两大创新点的讲法**：每个创新点都用「一句定义 → 一次完整操作 → 一句机制解释」三段式；学习路径三镜之间用同一账号连续录，评委看的是一条不断推进的线，不是三个孤立页面。
- **失败预案**：AI 生成失败重发一次（网关偶发抖动，重启 nexora-web 后动画问题已修复）；节点快测出题超过 60s 就说"异步出题中，结果我提前准备好"切预录截图。
- **解说**：OBS 麦克风同步口播，语速放慢；创新点两段的解说词建议照稿念（本方案已写好）。
- **录完自检**：拼合 → 看总时长 → 按公式算码率 → 两遍压制 → 确认 <100MB → 完整回放一遍。

### 4.1 录制顺序纪律（v3 新增）

1. **先录不受布局影响的镜头**（对话/路径/积分/绘本/编程/管理端），最后录涉及界面位置与高亮的镜头；
2. **新手引导最后录**（计划 D 完成、且学生端布局冻结之后）：引导高亮依赖 `data-tour` 锚点在最终布局中的位置，
   布局一改就要重录；同时要按学段分别录一版脚本（小低 3 步 / 小高 5 步 / 初高 6 步）；
3. **二期新增镜头按"账号数据先备好"再录**：镜 A 需要该账号有签到与至少一次节点快测（否则徽章墙全灰、榜单只有自己）；
   镜 B 需要该账号有一个"掌握度 60 左右、练习过几次"的节点，才能演出"AI 引用真实数据"的效果；
4. **时长兜底**：v3 新增 4 镜合计约 3.9 分钟，全片会超过原 12 分钟目标。
   建议要么把原镜 2/4/5 各压 15 秒、镜 10/15 合并，要么把镜 C、镜 D 压成 20 秒快切（只留结论句）。
