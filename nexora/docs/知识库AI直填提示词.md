# 知识库 AI 直填提示词

> 用途：跳过「上传 PDF → AI 文档整理」的慢速链路，直接让大模型（DeepSeek / Qwen / Kimi 等）按系统入库规范产出知识文档 Markdown，批量填充管理端知识库。
> PDF 原始课本仍留在资源中心，供评委查阅原始资料。
> 产出规范对齐 `KnowledgeBaseBiz.importDir` 的 frontmatter 解析（`title/stage/knowledgePointName/difficulty` 四键）与 `AiStructureComponent` 的整理基调（摘要开头、层级标题、LaTeX 公式、纯正文）。
> **v2 校准**：已对照 2026-09-28 收到的管理端 AI 整理真实产出（义务教育教科书·语文二年级上册，PDF 分段整理稿 12 部分）校准格式与去噪要求，见文末「校准记录」。

## 使用流程（4 步）

1. **填参数**：复制下方提示词全文，把 `{...}` 参数替换为实际值（教材版本、学科、学段、知识点、章节范围、难度）。
2. **生成**：粘贴到 DeepSeek / Qwen / Kimi 等对话模型，一次生成一份文档。同一提示词换参数即可批量产出整套教材。
3. **存文件**：把输出原样保存为 md 文件，按学段放入对应目录（见下表）。**整编形态**：一个单元（或整册合并后）= 一个 md 文件 = 系统里一篇文档；文件内每个知识点以 `# 第X单元·X 课名` 一级标题独立成节（系统按一级标题分块向量化，检索粒度仍到「课」）。文件名建议 `{教材简称}-{册}-{单元}.md`，如 `语文二年级下册-第一单元.md`。
4. **导入**：管理端「知识库 → 扫描目录导入」，一键批量入库 + 自动向量化。

### 学段目录映射

| stage 枚举值 | 学段 | 存放目录（`nexora/knowledge/` 下） | 参考字数 |
|---|---|---|---|
| `PRIMARY_LOW` | 小学低年级（1-2 年级） | `primary-low/` | 500-900 |
| `PRIMARY_HIGH` | 小学高年级（3-6 年级） | `primary-high/` | 800-1500 |
| `JUNIOR` | 初中 | `junior/` | 1200-2000 |
| `SENIOR` | 高中 | `senior/` | 1500-2500 |

- 目录层级必须 ≥2 级（即 md 文件必须放在学段子目录内，不能直接放 `knowledge/` 根下）。
- 文件名即入库幂等键（按相对路径生成 docId），同一路径重复导入 = 更新不新增；改名 = 生成新文档，改名后需删除旧文档。
- **整编粒度选择**：推荐「一单元一文件」（单次生成约 3000-6000 字，模型一次可输出）；若要做「整册一文件」，把该册 8 个单元文件按顺序拼接、只保留文件头部的 frontmatter 即可，但**拼接后路径变化会生成新 docId**——直接在拼接后的文件上再导入即可，旧单元文件删除，避免重复入库。

## 提示词全文（v3）

```text
你是一名资深的 K12 教材编辑与课程设计专家。请根据下方给出的教材与知识点，输出一份可直接入库的 Markdown 知识文档，供 K12 人工智能通识课教学助手知识库使用。

【本次任务参数】
- 教材蓝本：{教材名称与版本，如：义务教育教科书·语文 二年级上册（人民教育出版社）}
- 学科：{语文 / 数学 / 英语 / 科学 / 信息科技 / 人工智能}
- 学段（stage）：{PRIMARY_LOW 或 PRIMARY_HIGH 或 JUNIOR 或 SENIOR}
- 学段对应年级：{如：小学一~二年级}
- 知识点名称（knowledgePointName）：{建议格式：{教材学科}·{册}·{单元}，如：语文·二年级下册·第一单元（春天）}
- 教材章节范围：{如：第一单元 第 1~4 课 + 口语交际 + 语文园地一（整编到单元）；或指定整册范围}
- 难度（difficulty，取值 1/2/3）：{如：1}

【输出格式要求（严格遵守）】
1. 只输出一份完整的 Markdown 文档，不要输出任何解释、前言、问候语，也不要输出"以下是整理结果"之类的说明。
2. 文档开头必须是 YAML frontmatter，键值之间用英文冒号加一个空格，值中不要包含英文冒号；四个键全量输出，取值必须来自上面参数，不得改写：

---
title: {整编范围标题，如：语文二年级下册·第一单元（春天）}
stage: {PRIMARY_LOW / PRIMARY_HIGH / JUNIOR / SENIOR}
knowledgePointName: {知识点名称，与参数一致}
difficulty: {1 / 2 / 3}
---

3. frontmatter 之后是正文。正文**不再设总标题**，直接按知识点（课）逐节输出，每个知识点以 `# {单元}·{序号} {课名}` 一级标题开头（如 `# 第一单元·1 古诗二首（村居·咏柳）`），其后紧跟：
   - `## 摘要`：用 3-5 句话概括本节核心知识与学习重点，语言符合该学段学生水平。
   - 一级标题是全文档的分块边界：系统按 `#` 开头行分块向量化，「一个一级标题 = 一个知识块」，因此每个知识点必须独立成节、不得拆分到多个一级标题下。
4. 正文组织要求：
   - 按教材对应章节的知识脉络展开，一级标题之下用二级（##）、三级（###）标题分层，一个主题一节；
   - 只整理本次章节范围内的内容，范围内容必须完整自洽，不允许出现"第x/N部分""本部分内容到此结束""后文未显示""内容截断"等分段数据痕迹；
   - 概念定义必须准确，讲解通俗、符合学段认知水平；原文照录或要点提炼按下方「学科特性」执行，不要逐字复制教材讲解性文字；
   - 每节应包含：核心概念与定义、原理或过程说明（分步骤用有序列表）、分类或对比内容（优先使用 Markdown 表格）、贴近学生生活的实例（小学低年级多用生活化类比，小学高年级引入真实场景，初高中可结合学科应用）；
   - 涉及规则、算法、公式时使用规范表示：公式用 LaTeX（行内 $...$，独立公式 $$...$$），代码片段用带语言标注的代码块（如 Python）；
   - 知识深度与语言难度必须匹配学段：小学低年级短句、少术语、多生活类比；小学高年级适度引入术语并即时解释；初中要求概念准确、逻辑清晰、可含少量公式；高中要求系统完整、可引入抽象概念与算法思想。
5. 学科特性（按学科保留教材应有的板块面貌）：
   - 语文：课文、诗词、寓言原文必须完整照录（不允许节选或截断）；保留「会认字/会写字/词语积累」等字词板块与课后练习；古诗、文言文保留原文、作者、朝代；对寓言、故事补一段「主旨与启发」；「本文选自……有改动」等作者出处注释可保留；
   - 数学/科学：概念、公式、性质一律用 LaTeX 书写（行内 $...$，独立公式 $$...$$），例题给出完整解题过程，保留教材典型习题与活动；涉及图形时用文字描述图形特征（本系统 Markdown 渲染支持 LaTeX，向量化按普通文本处理）；
   - 信息科技/人工智能：概念定义、原理与操作步骤（有序列表）、对比表格、示例代码或图形化积木组合描述、贴近学生生活与校园的应用实例；
   - 英语：课文/对话原文、生词表（含音标）、重点句型、语法点简析、练习；
   - 其他学科按同类原则自然处理。
6. 全文末尾附「例题」与「练一练」两个小节（用二级标题）：
   - 例题：1 道与本知识点直接相关的示例题，给出完整解答过程（语文学科可改为「课后练习」原样保留后，再补充 1 道理解思考题）；
   - 练一练：2-3 道判断题或填空题或简答题，随后另起"参考答案"小节给出简明答案。
7. 正文总长度（不含 frontmatter）：小学低 500-900 字；小学高 800-1500 字；初中 1200-2000 字；高中 1500-2500 字，以讲透知识点为准，宁精勿水。语文学科需完整照录课文原文，字数可在此基础上上浮（课文原文、生字词与课后练习照录部分不计入字数上限）。
8. 质量红线：
   - 去噪：下列内容一律不出现——整册目录、版权页、出版与反馈信息（书名拼音、出版社电话/邮箱、意见反馈平台、"绿色印刷产品"等）、教材后记、编写与插图人员名单、页眉页脚、分页痕迹、连续空行；
   - 忠于教材与学科通识，不编造事实、数据与结论；对记忆不确切的具体数据或细节，改为表述通用结论并在该处注明"（以本教材为准）"；
   - 全文不使用 emoji，不使用口语化语气词；标点一律使用中文全角；
   - 只输出 Markdown 正文，禁止用代码块包裹整个文档。
```

## 已知约定与注意点

- frontmatter 四键中 `knowledgePointId` 不要写：系统缺省按 `kp:{stage}:{title}` 生成 UUID5，`knowledgePointName` 缺省建知识点，管理端可后续在「知识目录」里改名/挂接。
- 入库后系统按 `#` 标题切块（默认 500 字符/块）向量化，因此标题层级越清晰、每节越独立，检索效果越好。
- 正文内不要出现 frontmatter 风格的多余键（如 `tags:`），解析器只认上述四键，其余键会被忽略但 `TextChunker` 会剥离整个 frontmatter 块，多余键不影响正文。
- 此提示词与系统内置「AI 文档整理」（`AiStructureComponent` 硬编码提示词，单次 6000 字符分段）互不影响，两者产出的文档均可入库。
- 知识点名称建议带册次（如「语文·二年级下册·第一单元（春天）」），这样知识目录树里同名知识点（不同册次/单元）不混淆。
- **学科（subject）暂不写入 frontmatter**：`importDir` 解析器只认 title/stage/knowledgePointId/knowledgePointName/difficulty 五个键，其余键忽略；自动创建的知识点学科固定为 `AI`（`KnowledgeBaseBiz.ensureKnowledgePoint` 硬编码）。导入后需在管理端「知识目录」把知识点学科手动改为语文/数学/英语等对应学科（前端表单支持）。如需 frontmatter 直接支持 `subject` 键自动归类，需小改后端（约 5 行），确认后可以加。

## 校准记录

**v1 → v2（2026-09-28，对照真实整理产出校准）**：

管理系统「AI 文档整理」对语文二年级上册 PDF 的真实产出（12 部分分段整理稿）暴露如下问题，v2 已针对性规避：

| 真实产出问题 | v2 对策 |
|---|---|
| 每部分以「# 书名（第x/12部分）知识整理」开头，12 个大标题互相独立，同课被拆散 | 按知识点独立成节、内容完整自洽，禁止出现第x/N部分与截断字样 |
| 「本部分内容到此结束」「后文未显示」等截断残留 | 同上，要求完整照录课文 |
| 保留整册目录、教材后记、出版与反馈信息（电话/邮箱/平台） | 去噪清单逐条点名 |
| 无 frontmatter，无法走扫描目录批量导入 | v2 强制 frontmatter 四键 |
| 生字/词语/课后练习板块保留完整（可取之处） | v2 按学科特性要求保留这些板块 |

**v2 → v3（2026-09-28，使用反馈校准）**：

| 反馈 | v3 对策 |
|---|---|
| 一课一文件太散 | 整编形态：一个单元（或整册合并）= 一个 md 文件，文件内每课以 `# 第X单元·X 课名` 一级标题独立成节；已按此合并第一单元 6 课为 [knowledge/primary-low/语文二年级下册-第一单元.md](../knowledge/primary-low/语文二年级下册-第一单元.md) 示例 |
| 其他学科是否支持 | 系统支持多学科（subject 枚举），但扫描导入建知识点学科固定 AI，需管理端手动改；如需 frontmatter 支持 subject 需小改后端 |
| 数学公式 | 前端 MathMarkdown 支持 `$...$`/`$$...$$` LaTeX 渲染，提示词已要求数学/科学公式一律 LaTeX 书写 |

**结论**：旧管线按 PDF 分段（6000 字符/次）逐段整理再拼接，必然产生标题重复、内容截断与目录噪声；直填链路按整编粒度生成（文件内以一级标题分块），辅以上述去噪与完整性要求，质量与批量效率均优于旧管线。
