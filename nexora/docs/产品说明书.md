# Nexora 产品说明书

> 更新：2026-08-15
> 版本：当前开发版
> 说明：学生端按“年级”表达，内部用学段（小学低 / 小学高 / 初中 / 高中）分组；管理端以课程、习题、试卷组织教学业务。

## 1. 产品定位

Nexora 是面向 K12 的人工智能通识课教学助手。学生端提供 7x24 小时 AI 教师：对话答疑、知识检索、课程学习、动画讲解、个人知识库与资源管理。管理端负责课程、题库、试卷、官方知识库、资源和学习分析。系统只有“学生 + 管理员”两类角色，不设教师 / 班级 / 固定考试。

## 2. 年级与学段

- 用户年级从一年级到高三，可在「我的」页面修改。
- 学段由年级推导：小学低 / 小学高 / 初中 / 高中。
- 课程、题目、试卷按年级精确过滤；学段用于功能可见性与检索范围。

## 3. 学生端

### 3.1 登录与注册

- 邮箱 + 密码注册登录，支持验证码。
- 未登录可浏览 AI 助教、课程教材、我的等公开入口；受保护页面访问时自动弹出登录。
- 注册后默认创建个人资源中心目录，并分配 300MB 上传额度。

### 3.2 导航结构

| 用户 | 导航 |
|---|---|
| 未登录 | AI 助教、课程教材、我的 |
| 小学 | AI 助教、绘本生成、课程教材、资源中心、我的 |
| 初中 / 高中 | AI 助教、动画讲解、课程教材、编程环境、资源中心、学习路径、我的 |

### 3.3 功能页面

#### AI 助教

- WebSocket 流式对话，支持取消、会话历史。
- 意图路由：讲解、推荐、练习、动画等。
- 知识库检索：个人知识库 → 官方知识库 → 课程资源。
- 对话中可推荐学习材料，点击进入课程教材预览。

#### 动画讲解

- 面向初中 / 高中。
- AI 生成 HTML/SVG 动画，产物保存到资源中心，独立页面播放。
- 当前：入口与播放页已建，动画生成与播放能力持续完善。

#### 课程教材

- 按学生年级展示上架课程。
- 课程详情包含章节、课时、资源绑定。
- 支持视频（HLS）、图片、文档、链接预览。

#### 编程环境

- 面向初中 / 高中。
- 基于 Pyodide 在浏览器运行 Python。
- 当前：入口与基础环境已建，学习场景后续完善。

#### 资源中心（个人知识库）

- 树形目录 + 文件列表，支持新建 / 重命名 / 删除 / 同级拖拽排序。
- 分片上传、上传进度面板、批量删除。
- 白名单：md / txt / docx / pdf / ppt / pptx + 图片；总配额 300MB。
- 资源可预览、下载，后续可解析生成个人 wiki 页面并供 AI 检索。

#### 学习路径

- 面向初中 / 高中。
- 展示个性化学习路径，后期由学习行为记录动态生成。

#### 绘本生成

- 面向小学（当前页面限制为小学低年级）。
- 入口已建，绘本创作与翻页播放后续完善。

#### 我的

- 头像、昵称、邮箱。
- 修改年级（学段自动推导）。
- 退出登录。

## 4. 管理端

### 4.1 导航结构

工作台 / 用户管理 / 资源中心 / 知识库管理（官方知识库）/ 教学业务 / 学习分析 / 系统设置

### 4.2 功能页面

#### 工作台

- 平台数据总览：用户、资源、知识库、对话、学习行为等统计入口。

#### 用户管理

- 学生账号列表、新增、编辑、启禁用、删除。
- 按邮箱 / 年级 / 状态筛选。

#### 资源中心

- 统一管理所有资产：文件、视频、图片、SVG 动画、绘本、MD。
- 目录树、分片上传、视频转码（ffmpeg）、预览、下载、批量删除。
- 资源类型：视频 / 图片 / 文档 / 绘本 / 链接，不设音频。

#### 知识库管理（官方知识库）

- 知识总览、知识目录、问答测试。
- 文档录入、从资源导入、超链接录入。
- txt / md / docx / ppt / pdf 解析 → 分块 → 向量化入 ES；解析异步执行。
- PDF 扫描版提示 OCR 处理；当前 OCR 未接入。

#### 教学业务

- 课程管理：课程 → 章节 → 课时 → 资源绑定；课程、题目均按年级过滤。
- 习题管理：题目 CRUD、题型扩展（单选 / 多选 / 判断 / 填空 / 简答 / 解答 / 论述 / 材料分析）、难度、知识点、审核；AI 出题 + MD 自动导入；PDF 导入暂缓。
- 试卷管理：练习卷 / 测验卷，大题分组、题目选择与分值、排序、Markdown 导出。
- 无考试管理：7x24 AI 教师不设固定考试。

#### 学习分析

- 课程进度、练习正确率、个人知识库活跃、AI 对话量。

#### 系统设置

- 管理员账号、模型与提示词、环境配置。

## 5. 核心机制

- RAG：ES 向量检索 + 关键词回退，按年级 / 学段、知识点、难度过滤。
- 流式对话：Netty WebSocket，禁止同步阻塞。
- 个人知识库：`owner_id` 隔离，个人资料仅本人可见，默认优先级高于官方知识库。
- 异步处理：资源解析、视频转码、向量化统一走 Redis 队列。
- 题目公式：Markdown + LaTeX，后台与学生端统一 KaTeX 渲染。

## 6. 当前状态

- 已可用：登录注册、AI 对话、RAG、课程教材、资源中心、习题 / 试卷管理、学习分析、系统设置。
- 开发中：个人知识库解析与 wiki、动画讲解播放、学习路径、编程环境、绘本创作、PDF 题目导入。
