# 构建 Nexora 管理后台

## 构建整个框架页

```
1、阅读工作空间的要求以及 nexora 项目要求（2.claude配置.md：vue-admin-page / nexora-front）。
2、完成 nexora/nexora-front/nexora-front-admin 框架页面的构建，整体使用简洁清爽的蓝色调（学生端才是极光多彩主题）。
要求如下
- 页面分为上下两部分，上面左侧是 logo 以及项目名称，项目名称是：Nexora AI 教学助手后台，中间是一级菜单，右侧是登录用户信息，一级菜单体居左显示
- 页面下半部分分为左右两块，左侧是二级菜单，右侧是具体的功能页面，使用卡片样式显示两块内容
- 一级菜单选中状态为菜单展示下边框，颜色蓝色。二级菜单显示选中的一级菜单名称，然后展示二级菜单，二级菜单选中，二级菜单显示区域需要卡片形式显示，与右侧区域对齐
  状态为蓝色渐变 rgb(198, 222, 254)

```

## 构建表格组件

```
使用 elementplus el-table 构建一个 BaseDataTable.vue 组件，放到 /src/components 目录下。
要求
- 将 elementplus 中分页组件集成到表格中
- 表格支持复选
- 表格单元格支持自定义内容
- 表格应该撑满可见区域，表格根据内容自动计算高度，实现行内滚动，让外部页面不出现滚动条
- 表格宽度 100%
- 封装的表格边框参数对外，默认是无边框
- 表格支持数据渲染格式
{
    "totalCount": 1,
    "pageSize": 15,
    "pageNo": 1,
    "pageTotal": 1,
    "list": []
 }

- 调用该组件的页面只需要传入标题信息，比如标题名称，标题属性 key，标题宽度，插槽中自定义内容，数据源数据

封装完成后，在班级管理页面填充 200 条假数据，用来展示结果。
```

## 构建弹出框

```
1.使用 elementplus 封装一个弹出框组件 BaseDialog.vue。
要求
- 可以自定义标题
- 可以自定义宽度，宽度传入百分比，或者具体的宽度值
- 弹出框分为标题，内容，和底部按钮区域，按钮可以自定义事件和展示内容，取消按钮通过参数控制，取消按钮是 link 样式的按钮
- 提供距离顶部的参数，默认 30px
- 弹出框内容使用插槽，内容最高为页面高度，减去距离顶部的高度，排除标题和按钮占据的高度，超过高度内部出现滚动条
- 提供是否显示取消按钮的参数
- 提供是否展示右侧关闭按钮的参数
- 提供内容区域 padding 参数

-- 在用户管理页面添加新增管理的按钮，放在搜索卡片的右侧（不要紧贴搜索卡片，中间要空出距离），组件就使用封装好的 BaseDialog
-- 在用户管理页面的搜索卡片新增一个按状态搜索

2.使用 elementplus 封装一个抽屉组件 BaseDrawer.vue，要求跟 BaseDialog 弹出框类似
3.参照班级管理，完善学生管理页面，同样填充 200 条假数据。学生管理表单必须包含学段（stage：小学低年级 / 小学高年级 / 初中 / 高中）与年级字段。在学生管理页面新增按钮需要使用封装好的 BaseDrawer
4.封装封面组件，支持课程封面，个人头像等，可以自定义图片宽度，圆角大小，高宽比。（这个目前用不到，先放着）
```
