# Nexora 本地启动指南（IDEA 后端 + VSCode 前端）

> 更新：2026-08-12 ｜ 端口：后端 mcp=8084、admin=6061、web=6060(WS 6062)；前端 admin=3001、web=3000
> 前置：MySQL(3306, 库 nexora 28 张表)、Redis(6379, db1)、Elasticsearch(9200) 已启动

## 一、后端：IDEA 启动（顺序：mcp → admin → web）

1. 用 IDEA 打开后端工程：`D:\dev\ai\k12\nexora\nexora-java\`（打开根 pom.xml，等待 Maven 依赖下载完成）
2. 依次运行 3 个启动类（右键 → Run，或左侧运行配置）：
   | 顺序 | 启动类 | 端口 |
   |---|---|---|
   | 1 | `com.nexora.NexoraMcpServerApplication` | 8084 |
   | 2 | `com.nexora.admin.NexoraAdminApplication` | 6061 |
   | 3 | `com.nexora.NexoraWebApplication` | 6060 |
3. 启动成功标志（控制台日志）：
   - mcp：`Netty started on port 8084` / `Started NexoraMcpServerApplication`
   - admin：`Tomcat started on port 6061` / `Started NexoraAdminApplication`
   - web：`Tomcat started on port 6060` / `Started NexoraWebApplication`
4. 先启动 mcp 再启动 web（web 启动时会自动连接 mcp，连接失败只是警告不阻塞）

> 注意：IDEA 首次打开多模块工程会较慢；如果找不到启动类，先右键根 pom → Add as Maven Project。

## 二、前端：VSCode 启动（React 首次使用必读）

### React 是什么、怎么运行
- React 项目**不是双击 html 打开**，而是通过 Node.js 跑一个“开发服务器”，在终端里敲命令启动。
- 开发服务器会**监听文件变化**：你保存代码后浏览器页面自动刷新（热更新 HMR），不需要手动刷新。
- 启动后**终端不能关**（关了服务就停了）；停止用 `Ctrl + C`。

### 首次运行步骤（每个前端工程只需做一次 npm install）
1. 用 VSCode 打开前端工程目录（**两个工程是独立文件夹，需要分别打开/分别开终端**）：
   - 管理后台：`D:\dev\ai\k12\nexora\nexora-front\nexora-front-admin`
   - 学生端：`D:\dev\ai\k12\nexora\nexora-front\nexora-front-web`
2. 打开终端：菜单 Terminal → New Terminal（或快捷键 `Ctrl + \``）
3. 在终端输入（首次需要，安装依赖，约 1-3 分钟）：
   ```bash
   npm install
   ```
4. 启动开发服务器：
   ```bash
   npm run dev
   ```
5. 看到类似输出即成功（会显示访问地址）：
   ```
   VITE v8.x.x  ready in xxx ms
   ➜  Local:   http://localhost:3001/
   ```
6. 浏览器访问：
   - 管理后台：http://localhost:3001 （账号 admin / 密码 123456）
   - 学生端：http://localhost:3000

### 前端常用命令
| 命令 | 作用 |
|---|---|
| `npm install` | 安装依赖（首次/删过 node_modules 时） |
| `npm run dev` | 启动开发服务器（日常开发用） |
| `npm run build` | 打包生产版本（构建验证用） |
| `Ctrl + C` | 停止服务 |

### 常见问题
| 现象 | 处理 |
|---|---|
| `EADDRINUSE` / 端口被占用 | 端口被别的进程占用，找到占用进程关掉或改端口 |
| `'npm' 不是内部或外部命令` | Node.js 未安装或未配置 PATH（需 Node ≥ 20） |
| 改了代码没反应 | 确认终端里 dev 服务还在运行；保存后稍等 1-2 秒 |
| 页面能开但接口报错 | 先确认 3 个后端都启动成功（尤其 6061/6060） |

## 三、联调自检（启动完成后）

1. 浏览器打开 http://localhost:3001 → 用 admin / 123456 登录 → 进入工作台
2. 浏览器打开 http://localhost:3000 → 能看到学生端 5 个页面骨架
3. 后端自检（可选）：
   ```
   curl -X POST http://localhost:6061/api/account/login -H "Content-Type: application/json" -d '{"username":"admin","password":"123456"}'
   ```
   应返回 `{"status":"success","code":200,...,"data":{"token":"...","userInfo":{...}}}`
