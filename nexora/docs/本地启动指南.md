## 3. AI 环境变量

AI Key 一律通过环境变量注入，禁止硬编码。DeepSeek 与阿里百炼是两个平台，Key 不能混用；百炼的 embedding 和 image 可共用 `NEXORA_DASHSCOPE_API_KEY`。

| 变量 | 必填 | 说明 |
|---|---|---|
| `NEXORA_DEEPSEEK_API_KEY` | 是 | DeepSeek：对话、意图路由、SVG 动画、编程辅助 |
| `NEXORA_EMBEDDING_API_KEY` | 否 | 向量化；缺省回退 `NEXORA_DASHSCOPE_API_KEY` |
| `NEXORA_IMAGE_API_KEY` | 否 | 绘本插图；缺省回退 `NEXORA_DASHSCOPE_API_KEY` |

常用可选变量：

| 变量 | 默认值 |
|---|---|
| `NEXORA_CHAT_MODEL` | `deepseek-v4-flash` |
| `NEXORA_CHAT_BASE_URL` | `https://api.deepseek.com` |
| `NEXORA_EMBEDDING_MODEL` | `qwen3.7-text-embedding` |
| `NEXORA_EMBEDDING_DIMENSIONS` | `1024` |
| `NEXORA_IMAGE_MODEL` | `qwen-image-3.0` |
| `NEXORA_DASHSCOPE_API_KEY` | 否 | 阿里百炼统一 Key |
| `NEXORA_MAIL_USERNAME` | 是 | QQ 邮箱账号 |
| `NEXORA_MAIL_PASSWORD` | 是 | QQ 邮箱授权码 |
| `NEXORA_MCP_CLIENT_ENABLED` | 否 | 默认 `false`；开启 MCP 时设 `true` |
| `NEXORA_TOKEN_SECRET` | 否 | 登录 Token 派生密钥，仅开发默认值 |
Windows 配置方式：

```powershell
# 当前终端临时生效
$env:NEXORA_DEEPSEEK_API_KEY = "sk-..."
$env:NEXORA_EMBEDDING_API_KEY = "sk-..."
$env:NEXORA_IMAGE_API_KEY = "sk-..."

# 用户级永久生效（新终端 / IDE 生效）
setx NEXORA_DEEPSEEK_API_KEY "sk-..."
setx NEXORA_EMBEDDING_API_KEY "sk-..."
setx NEXORA_IMAGE_API_KEY "sk-..."
```

IDEA 需在 `Run/Debug Configurations -> Environment variables` 中填写，或完全重启 IDEA 后读取 `setx` 的变量。启动日志提示 `AI 环境变量已生效` 即配置成功。

## 4. 数据库初始化

全新部署（只建结构、不含数据）：

```cmd
mysql -uroot -p < nexora\docs\nexora_schema.sql
```

`nexora_schema.sql` 已包含 `CREATE DATABASE` 与当前 34 张表。

## 5. 后端启动

在 `nexora-java` 目录执行：
配置maven,字符编码，jdk版本

然后按顺序启动 3 个服务（IDEA 右键运行启动类，或使用 Maven Spring Boot 插件）：

| 顺序 | 启动类 | 端口 |
|---|---|---|
| 1 | `com.nexora.NexoraMcpServerApplication` | 8084 |
| 2 | `com.nexora.admin.NexoraAdminApplication` | 6061 |
| 3 | `com.nexora.NexoraWebApplication` | 6060 + 6062 |

MCP 可选：`nexora-web` 默认 `NEXORA_MCP_CLIENT_ENABLED=false`，不启动 MCP 也可运行；开启 MCP 时先启动 8084。

## 8. 常见问题

| 现象 | 处理 |
|---|---|
| 端口被占用 | `netstat -ano | findstr 6061` 定位进程并关闭，或调整 `application.yml` 端口 |
| 后端 401 | 环境变量未读到，完全重启 IDEA，确认 `NEXORA_*` 已配置 |
| RAG 检索失败 | 确认 ES 9200 已启动，向量索引维度与 `NEXORA_EMBEDDING_DIMENSIONS` 一致 |
| MCP 端口 8084 被占用 | 不需要 MCP 时保持 `NEXORA_MCP_CLIENT_ENABLED=false` |
| 表或字段缺失 | 重新执行 `nexora.sql` 与 `sql/` 下全部迁移脚本 |
