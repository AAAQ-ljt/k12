# 适用前提

- 工程：`nexora-front-web`，技术栈 React 18 + TS + Vite + Zustand + antd v5 + SCSS（CSS Modules）。
- 面向学习场景，使用卡片 / 列表 / 图表 / 对话布局，禁止套用后台表格 UI。
- 全部中文；学生端使用"极光"主题（多彩渐变、圆角卡片、大字号、图标化）。
- 学段适配：按 `userInfo.stage` 切换 UI 密度、入口可见性、内容深度；低龄学段大按钮 / 图形化 / 少文字，高中可承载代码 / 图表。

# 页面结构（固定 5 页）

1. AI 助教（`AgentChat`，首页 / 对话区）。
2. 个性化学习路径（`LearningPath`）。
3. 课程教材（`CourseLibrary`）。
4. 编程环境（`CodeLab`，小学高年级及以上可见）。
5. 我的（`Profile`）。

练习不单设页面：以"对话内答题卡片 + 路径节点快测"承载。

# AI 助教（首页）

- 结构：会话列表（左）+ 对话区（右）。
- 发送：调 `/api/agent/sendMessage`，通过统一 WebSocket 封装接收流式增量；状态机 streaming / done / error / cancelled。
- 消息渲染：react-markdown（代码块高亮）；工具调用结果显示为卡片（推荐材料卡 → 跳转课程教材对应资源；练习卡 → 内嵌答题；动画卡 → SVG 播放器；绘本卡 → 翻页器）。
- 输入模式：输入框可切换"动画讲解"模式（输入概念如"冒泡排序"→ 生成 SVG 动画）；低龄学生显示"绘本"入口（可输入主题生成，也可浏览管理员预置绘本库）。
- 主动引导：进入页面 / 进入课时时，AI 基于学习路径当前节点主动发起对话，不被动等待提问。
- 材料推荐：每轮回答结束后 AI 询问"是否需要推荐相关学习材料"，学生确认后以卡片展示（视频 / 文档 / PPT），点击跳转课程教材页对应资源。
- 交互：发送中禁用输入、支持取消（`cancelMessage`）、支持重新生成；历史消息分页加载；切换学段 / 知识点时提示新建会话。

# 个性化学习路径

- 知识点节点地图：可视化节点图，三态——已掌握（绿）/ 进行中（蓝）/ 未解锁（灰）；核心必学节点构成主线，兴趣分支供自主选择。
- 分类创建：学生可自主创建学习分类，AI 根据分类目标生成对应学习路径（`createStudyPath`）。
- 短期目标清单：AI 将长期目标拆解为阶段性 List，学生逐项完成并勾选。
- AI 动态调整：完成当前阶段后自动生成下一阶段目标；未通过的知识点回补路径，已掌握的加速跳过。
- 遗忘曲线复习：已掌握知识点按间隔周期（1/3/7/15 天）自动安排复习节点，简短快测检验；未通过则重新标记为"进行中"。

# 课程教材

- 按学科 / 学段 / 章节分类展示管理员上传的教学资源（视频 / Word / PPT / 绘本），支持在线阅读或下载。
- 从首页推荐卡片跳转时直接定位到对应资源。
- 视频统一走项目封装的播放组件（ArtPlayer + HLS + 进度续播）：进入课时取最后播放时间点续播；播放中节流（5 秒）上报进度，接口设为静默错误。

# 编程环境（CodeLab）

- 结构：Monaco 封装编辑器 + 运行按钮 + 运行结果 / 控制台 + 题目说明；预置代码框架可运行。
- 运行：Python 用 Pyodide 在浏览器端执行（无服务端沙箱风险）；JS 可走 sandboxed iframe。
- 与学习路径联动：学习路径中进入编程知识点时 AI 主动引导进入本页并预置对应代码框架；练习结果自动回写，作为知识点掌握判定依据之一。
- 学段可见性：小学低年级不展示本页入口。

# 我的

- 学段选择 / 切换：切换后全局交互风格、知识库范围、功能可见性自动适配。
- 学习数据仪表盘（ECharts）：知识掌握雷达图、学习时长统计与连续打卡天数、AI 推荐路径与实际学习路径对比图、学习风格标签（如"视觉型学习者""实践型学习者"）。
- 已保存内容：集中展示下载或自动保存的动画讲解（可下载 SVG）、生成的绘本等产物。
- 学习历史记录：按时间线展示对话记录、完成的练习、掌握的知识节点。

# 对话内多模态组件（src/components/multimodal/）

- `SvgAnimationPlayer`：分步 SVG + 讲解文案，上一步 / 下一步 / 重播 / 下载保存。
- `PictureBookViewer`：图文翻页（大图大字，低龄适配），可选 TTS 朗读（浏览器 SpeechSynthesis）。
- `QuizCard`：单选 / 多选 / 判断 / 填空逐题作答 + 即时反馈（正确 / 错误 + 解析）+ 得分 / 星星 / 徽章激励；提交走练习接口，后端自动批改。
- `CodeEditorCard`：Monaco 封装的轻量代码卡。

# 学习记录约定

- 学习进度字段命名与后端 PO / VO 一致，禁止前端起别名。
- 失败容忍：进度上报失败不影响学习体验，由后端通过 Redis 缓冲做最终一致。
- 切换课时 / 离开页面时主动上报一次最新进度。

# 接口封装

- 一个场景一个 api 文件，导出业务方法与 TS 类型（如 `loadMyCourses`、`getCourseDetail`、`reportLessonProgress`、`sendMessage`、`submitPractice`）。
- 接口请求统一走项目封装的 request 实例；AI 回复走统一 WebSocket 封装。
- 列表接口在 api 层做返回值兜底归一。
- 静默场景（进度上报、心跳）在调用时关闭错误弹窗。

# 自检清单

- 使用卡片 / 列表 / 图表 / 对话布局，没有后台表格组件。
- 视频走项目封装的播放组件。
- 字段名与后端 PO / VO 完全一致。
- 页面里没有 axios import；AI 流式没有自拼 fetch / WebSocket。
- 学段适配生效：低龄大字号 / 大按钮 / 图形化；小低无编程入口。
- 学习数据写入接口设为静默错误。
- 多模态组件集中在 `src/components/multimodal/`。

# 与其他 skill 的分工

- 本 skill：怎么写一个学生端业务页面（5 页结构 + 视频 + 学习进度 + AI / 多模态）。
- `nexora-front` skill：前端工程入口与跨页面话题（请求层、登录态、WebSocket 封装、env、字段一致性）。
- `nexora-multimodal` skill：多模态内容生成与前端渲染的后端约定（绘本 / SVG 动画 / 绘画 / 编程 / 练习）。
- `react-admin-page` skill：管理后台页面。
