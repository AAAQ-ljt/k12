# 适用前提

- 工程：`nexora-front-admin`，技术栈 React 18 + TS + Vite + Zustand + antd v5 + SCSS（CSS Modules）。
- 三段式（强制）：搜索区 → 表格 → 分页；新增 / 编辑必须用弹窗；删除必须二次确认。
- 中文界面；状态列用 `Tag`；下拉选择即触发搜索。

# 一个完整管理页对应的产物

- 列表页：`src/views/<业务子目录>/XxxManagement.tsx`。
- 表单弹窗：`src/views/<业务子目录>/XxxFormModal.tsx`（与列表页同目录，独立文件）。
- 接口封装：`src/api/<模块>.ts`（内含请求 / 响应 TS 类型）。
- 路由 / 菜单配置：在路由配置与菜单配置文件里登记，`meta` 带"是否需要登录"与"菜单编码"。

# 列表页结构（搜索区 → 表格 → 分页）

- 搜索区：行内表单（`Form` inline），常见控件为 `Input`、`Select`（学段、知识点、状态）、`DatePicker`。`Select` 绑定 `onChange` 立即触发查询；`Input` 支持回车触发。提供"查询"与"重置"按钮。
- 操作区：搜索区下方放新增、批量操作、导入 / 导出等按钮。按钮按权限编码（`hasMenuCode`）控制显隐。
- 表格区：直接使用项目封装的标准表格组件（封装 antd `Table` + 分页 + 选中 + 排序）。
  - 列：业务字段 → 状态列（`Tag`）→ 时间列 → 操作列（`fixed: 'right'`）。
  - 操作列固定三个动作：查看 / 编辑 / 删除，按权限编码控制显隐。
- 分页区：由标准表格组件内置，无需单独写。

# 表单弹窗结构

- 独立文件，props 包含：`open`（显示开关）、`mode`（create / edit / view）、初始数据模型，以及业务下拉所需的选项数据（学段、知识点等）。
- 事件：`onCancel`（关闭）、`onSuccess`（提交成功，通知父组件刷新列表）。
- 表单使用 `Form` + `rules` 校验；规则定义在弹窗组件内部，与字段共维护。
- 查看模式整体只读（`disabled` 整表禁用），不显示底部"保存"按钮。
- 提交逻辑：先 `validateFields`，再根据模式分别调用新增 / 修改接口，成功后 `message.success` 并通知父组件。

# 管理端常见业务页

- 课程体系：课程（教材）/ 章节 / 课时 / 资源管理（学段字段作为筛选与表单项）。
- 知识点管理：学段 / 难度 / 关联课时。
- 题库管理：题目 / 选项 / AI 出题审核状态。
- 知识库管理：知识文档（标题、学段、知识点、难度、内容、向量状态）、上传资料解析入库、重新入库按钮、检索测试。
- 智能体配置：提示词管理（按学段 / 场景编辑，保存后写 Redis 覆盖默认值）；会话质检（查看 agent_session / agent_message）。
- AI 内容：生成记录管理（类型、来源、学生、状态、预览 / 删除 / 发布为预置绘本）。
- 学生管理：学生列表（学段 / 年级筛选）、学习分析概览。

# 自检清单

- 三段式：搜索区 → 表格 → 分页。
- 新增 / 编辑走独立弹窗组件；删除二次确认。
- 操作列查看 / 编辑 / 删除按权限显隐。
- 下拉筛选即触发查询。
- 状态用 `Tag`。
- 接口全部走 `src/api/`，页面没有 axios。
- 学段等枚举值来自后端选项接口或统一常量，不硬编码。

# 与其他 skill 的分工

- 本 skill：怎么写一个管理后台页面（结构 + 弹窗 + 分页）。
- `nexora-front` skill：前端工程入口与跨页面话题（请求层、登录态、env、字段一致性）。
- `react-web-page` skill：学生端页面。
